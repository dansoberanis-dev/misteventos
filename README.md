# Mist Eventos

Site institucional estático, sem dependências de compilação. Recriado a partir dos prints enviados, preparado para edição e futura publicação no GitHub e na Vercel.

## Prévia local

Na pasta do projeto, execute `python3 -m http.server 8000` e acesse http://localhost:8000. Também é possível abrir `index.html` diretamente no navegador.

## Publicação futura

Envie o conteúdo desta pasta para um repositório no GitHub e importe o repositório na Vercel. Escolha o framework “Other”, sem comando de build; o arquivo `index.html` será servido diretamente. Nenhuma publicação foi feita automaticamente.

## Importante: verificar antes de publicar

- A foto `espaco-mist.jpg` foi fornecida pelo usuário. As outras fotos foram geradas por IA e são identificadas no site como ilustrativas; não representam o espaço real.
- Capacidade, nota, serviços, horários, telefone, e-mail e outros dados foram reproduzidos dos prints e precisam de confirmação.
- Os depoimentos foram reproduzidos como exemplos de layout dos prints e precisam de confirmação de autenticidade e autorização ou substituição.
- O formulário abre o WhatsApp com mensagem preenchida, para o número mostrado nos prints (`5541988265923`); confirme o número antes de publicar. Os demais botões utilizam o link wa.me/message presente na captura do Instagram.
- As fontes usam Google Fonts, com alternativas locais caso não estejam disponíveis.

## Arquivos

- `index.html`: conteúdo e links.
- `style.css`: aparência e responsividade.
- `script.js`: menu móvel, filtros da galeria, visualização de imagens e formulário para WhatsApp.
- `assets/`: imagens e logotipo com fundo transparente.
